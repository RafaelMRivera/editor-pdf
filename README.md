# PenFich

Notas, PDF e imágenes (JPG/PNG) como PWA: biblioteca de apuntes, plantillas, lápiz con presión, resaltador, borrador, lazo,
formas, texto, firma, imágenes, exportar a PDF/imagen y copia de seguridad. Pensada para tablet con lápiz (Lenovo Tab + Lenovo Pen).

- `npm run dev` — desarrollo (http://localhost:5173)
- `npm run build` — genera `dist/` (subir a un hosting con HTTPS: Netlify, Cloudflare Pages, GitHub Pages, Vercel)
- `npm run preview` — prueba la versión de producción

## Instalar en el celular / tablet
Abre la dirección https:// de la app en Chrome (Android) o Safari (iOS):
- Android: ⋮ (tres puntos) → **Instalar aplicación**
- iPhone/iPad: Compartir → **Añadir a pantalla de inicio**

Es una app web instalable (PWA): no hay APK, se instala desde el navegador y funciona sin conexión.
